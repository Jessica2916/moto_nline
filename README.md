
# Motonline 🚀

Um projeto web simples com sistema de **login**, **cadastro de usuários**, **recuperação de senha** e **tela de boas-vindas personalizada**, feito com HTML, CSS e JavaScript. Ideal para iniciantes que estão aprendendo como funciona o `localStorage` no navegador e a manipulação de interfaces dinâmicas.

## 🧠 Objetivo

O objetivo do projeto é simular um sistema de autenticação básica de usuários utilizando `localStorage`, sem conexão com banco de dados. É voltado para aprendizado e portfólio.

---

## 🔐 Funcionalidades

- [x] Tela de login com validação de usuário e senha  
- [x] Tela de cadastro de novos usuários  
- [x] Armazenamento local de dados usando `localStorage`  
- [x] Recuperação de senha simples (mostra a senha salva)  
- [x] Tela de boas-vindas com nome do usuário  
- [x] Botão de sair (logout)

---

## 💻 Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- `localStorage` para salvar dados localmente no navegador

---

## ▶️ Como usar

1. Clone ou baixe este repositório
2. Abra o `index.html` em qualquer navegador moderno
3. Crie um usuário na aba de cadastro
4. Faça login com os dados cadastrados
5. Você será redirecionado(a) para a tela de boas-vindas
6. Clique em "Sair" para voltar ao login

---

## ⚠️ Observações

- Os dados são salvos apenas localmente (`localStorage`), não sendo um sistema de autenticação real.
- Ideal apenas para testes, estudos ou portfólio.
- A recuperação de senha não envia e-mail, apenas mostra a senha diretamente (não recomendado em produção).
